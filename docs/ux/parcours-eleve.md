# Parcours Élève du MVP

## E-01, arriver sur l’accueil Élève

**Entrée :** `/eleve`.

1. L’élève voit un objectif principal.
2. L’élève identifie la durée estimée.
3. L’élève peut lancer l’activité principale.
4. Les autres options restent secondaires.

**Sortie :** activité, progression ou aide.

## E-02, lancer une activité courte

1. L’élève active le bouton principal.
2. Un état de chargement compréhensible apparaît.
3. L’activité s’ouvre.
4. L’élève répond.
5. Une rétroaction descriptive apparaît.
6. L’élève choisit Réessayer ou Continuer.

## E-03, consulter la progression

1. L’élève ouvre Progression.
2. Les informations sont présentées avec texte et indicateurs visuels.
3. Les acquis et prochaines étapes sont distingués.
4. Aucun classement avec d’autres élèves n’est affiché.

## E-04, contenu indisponible

1. Expliquer que l’activité ne peut pas être ouverte.
2. Éviter les codes et messages techniques.
3. Proposer Réessayer ou Retour à l’accueil.
4. Conserver le contexte de l’élève.

## E-05, réseau dégradé

1. Afficher un message court.
2. Indiquer si l’action est enregistrée ou non.
3. Désactiver les doubles soumissions.
4. Proposer une nouvelle tentative.

## Règles UX adaptées à l’âge

- phrases courtes ;
- une action principale par zone ;
- boutons suffisamment grands ;
- texte associé aux icônes ;
- focus visible ;
- erreurs sans culpabilisation ;
- encouragements liés à l’effort ou à l’action, pas à une promesse de réussite ;
- aucune mécanique de récompense trompeuse.
