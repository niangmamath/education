# Navigation de l’espace Élève

## Navigation principale

Ordre proposé :

1. Accueil
2. Activités
3. Progression
4. Récompenses

## Principes

- quatre destinations principales au maximum ;
- libellé visible avec chaque icône ;
- termes courts et concrets ;
- une action principale clairement distinguée dans chaque écran ;
- aucune navigation sociale ou classement entre élèves.

## Bureau et tablette

- navigation latérale ou supérieure simple ;
- zone de contenu large ;
- activité principale visible sans défilement excessif ;
- aide toujours repérable.

## Mobile

- navigation principale accessible sans geste caché ;
- cibles tactiles larges ;
- texte non tronqué ;
- orientation portrait prioritaire ;
- réorganisation sans perte de sens au zoom.

## Activités

Le lancement d’une activité doit conserver un chemin de retour clair vers :

- l’accueil Élève ;
- la liste des activités ;
- la progression après un résultat.

La fermeture accidentelle d’une activité ne doit pas être présentée comme une réussite.

## États système

### Contenu indisponible

Message court, bouton Réessayer, bouton Retour à l’accueil.

### Réseau dégradé

Indiquer clairement si la réponse a été enregistrée. Éviter toute double soumission.

### Session expirée

Expliquer qu’une nouvelle connexion est nécessaire sans afficher de détails techniques.

## Liens actifs

- `/eleve` active Accueil ;
- `/eleve/activites` active Activités ;
- `/eleve/progression` active Progression ;
- `/eleve/recompenses` active Récompenses ;
- une activité imbriquée conserve Activités comme destination active.
