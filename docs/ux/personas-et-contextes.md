# Personas et contextes d’utilisation

## Portée

Ces profils décrivent les utilisateurs cibles du MVP StudentConnect. Ils servent à guider l’UX et ne représentent pas des personnes réelles.

## Visiteur non connecté

### Objectifs

- comprendre rapidement la proposition de valeur ;
- identifier les publics concernés ;
- accéder à la connexion ou à l’inscription ;
- trouver de l’aide et les informations légales.

### Contraintes

- ne connaît pas encore le vocabulaire StudentConnect ;
- peut utiliser un mobile et un réseau limité ;
- doit distinguer les fonctions disponibles des fonctions encore en développement.

## Parent ou responsable familial

### Objectifs

- obtenir une vue synthétique de la progression d’un enfant ;
- choisir l’enfant consulté lorsque plusieurs profils existent ;
- comprendre les points acquis et les difficultés ;
- identifier une prochaine action simple ;
- consulter les activités, notifications et paramètres familiaux.

### Contraintes

- temps disponible limité ;
- niveau de familiarité numérique variable ;
- besoin d’explications simples et non techniques ;
- besoin de confidentialité entre les dossiers des enfants.

### Informations prioritaires

1. enfant actuellement sélectionné ;
2. date de dernière mise à jour ;
3. synthèse de progression ;
4. difficultés nécessitant une attention ;
5. activités recommandées ;
6. prochain geste utile.

## Élève de 6 à 11 ans

### Objectifs

- comprendre immédiatement ce qui peut être fait ;
- lancer une activité courte ;
- voir une progression simple ;
- recevoir une rétroaction compréhensible ;
- retrouver les activités commencées.

### Contraintes

- lecture et autonomie variables selon l’âge ;
- attention limitée ;
- besoin de cibles tactiles larges ;
- besoin d’icônes accompagnées de texte ;
- aucune pression sociale, culpabilisation ou classement public.

### Informations prioritaires

1. objectif du moment ;
2. activité principale ;
3. durée estimée ;
4. progression ;
5. résultat expliqué ;
6. prochaine action.

## Contextes transversaux

- utilisation mobile ;
- utilisation sur ordinateur familial ;
- réseau lent ou interrompu ;
- première visite ;
- dossier incomplet ;
- aucune donnée disponible ;
- session expirée ;
- contenu temporairement indisponible.

## Principes de confidentialité

- ne jamais afficher les données d’un autre enfant par défaut ;
- ne jamais utiliser de nom réel dans les démonstrations versionnées ;
- signaler clairement les données fictives ;
- réserver la liaison entre identifiant pseudonyme et utilisateur au backend futur.
