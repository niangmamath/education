# Prompt 07.2, créer le diagnostic initial pilote

Construire un diagnostic fictif mais cohérent avec le référentiel pilote.

## Exigences

- au moins deux compétences évaluées ;
- résultats par compétence ;
- niveau provisoire, fraîcheur et confiance ;
- aucun diagnostic psychologique ;
- données réinitialisables.

Créer le rapport avec les règles de conversion de score vers niveau.
