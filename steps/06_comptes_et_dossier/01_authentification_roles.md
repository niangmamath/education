# Prompt 06.1, implémenter authentification et rôles

## Travaux

- modèle utilisateur conforme aux décisions existantes ;
- inscription parent ;
- connexion, déconnexion et récupération de mot de passe ;
- rôles Parent, Élève, Admin et Valideur facultatif ;
- permissions objet ;
- tests d’accès négatifs.

Ne change pas le modèle User après des migrations partagées sans ADR et plan de migration.

## Critères

- un parent ne voit pas un enfant non lié ;
- aucune élévation de privilège ;
- flux mobile fonctionnel.
