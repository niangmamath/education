# Prompt 06.2, implémenter les relations familiales

Créer FamilyRelation avec rôle, dates, statut, source et révocation.

## Fonctionnalités

- créer un enfant fictif ;
- inviter ou simuler un second tuteur ;
- révoquer une relation ;
- journaliser les changements ;
- gérer plusieurs enfants.

## Critères

- relation datée et traçable ;
- accès supprimé après révocation ;
- tests de permissions passés.
