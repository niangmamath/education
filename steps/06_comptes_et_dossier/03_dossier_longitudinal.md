# Prompt 06.3, implémenter le dossier longitudinal

## Fonctionnalités

- dossier actif unique ;
- profil scolaire minimal ;
- objectifs et matières ;
- chronologie ;
- source, auteur, date et statut ;
- vue parent et vue élève adaptées.

## Critères

- unicité garantie en base ;
- cinq événements fictifs visibles ;
- historique lisible sur mobile ;
- aucune donnée médicale.
