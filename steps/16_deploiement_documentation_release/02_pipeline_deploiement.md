# Étape 16.2, créer le déploiement

## Prérequis

Lire les fichiers racine et le dernier rapport disponible.

## Objectif

Déployer frontend, API, workers et données de démo.

## Travaux obligatoires


1. Créer images Docker de production.
2. Configurer migrations contrôlées.
3. Configurer secrets via plateforme.
4. Activer HTTPS et domaines.
5. Configurer S3/CDN.
6. Configurer health checks et rollback.
7. Déployer d’abord en démonstration.


## Critères d’acceptation


- [ ] Application accessible en HTTPS.
- [ ] Secrets absents du dépôt.
- [ ] Migration et rollback documentés.
- [ ] Health checks verts.


## Livrables

Environnement de démonstration et rapport.

## Clôture obligatoire

- Exécuter les tests pertinents.
- Créer un rapport selon `MODELE_RAPPORT.md` dans ce dossier.
- Mettre à jour `ETAT.md`.
- Mettre à jour la ligne correspondante de `PLANNING.md`.
- Ne pas passer à la sous-étape suivante si le statut est `Bloqué`.
