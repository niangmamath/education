# Prompt 11.1, créer les données de démonstration

Créer trois profils fictifs :

1. parcours nominal avec amélioration ;
2. lacune persistante nécessitant adaptation ;
3. ressource externe indisponible avec fallback.

## Contraintes

- noms explicitement fictifs ;
- aucune donnée réelle ;
- fixtures réinitialisables ;
- parcours alignés sur le référentiel.

Documenter la commande de réinitialisation et produire le rapport.
