# Prompt 11.4, vérifier accessibilité et sécurité de base

## Vérifier

- écran 360 px ;
- navigation clavier ;
- labels de formulaires ;
- contrastes ;
- permissions objet ;
- CSRF ;
- secrets ;
- données personnelles dans URL/logs ;
- CSP iframe ;
- dépendances vulnérables disponibles localement.

Documenter les limites. Ne prétends pas réaliser un audit de sécurité certifié.
