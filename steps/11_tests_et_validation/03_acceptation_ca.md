# Prompt 11.3, exécuter CA-01 à CA-15

Créer ou mettre à jour les issues de type Test dans la vue `Validation finale`.

Pour chaque critère :

- préconditions ;
- étapes ;
- résultat attendu ;
- résultat observé ;
- preuve ;
- Acceptance : Passed, Failed, Not tested ou N/A ;
- bug lié si échec.

Ne marque pas Passed sans preuve.

Créer `docs/validation/acceptation-v0.1.md` et le rapport.
