# Prompt 03.3, implémenter le référentiel et les compétences

Implémente uniquement après validation du modèle.

## Travaux

- modèles Django Framework, Subject, Competency, CompetencyRelation et ExpectedLevel ;
- admin Django ;
- validations de cohérence ;
- migrations ;
- fixtures pilotes ;
- tests unitaires des relations et de l’historique.

## Critères

- 10 à 20 compétences importables ;
- matières et compétences transversales distinguées ;
- relation prérequis testée ;
- migrations réversibles ;
- admin exploitable.
