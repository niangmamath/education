# Prompt 08.3, créer l’explication et la validation humaine

## Vue attendue

- observations localisées ;
- matières concernées ;
- compétence commune ;
- preuves ;
- niveau de confiance ;
- pourquoi le système propose cette hypothèse ;
- actions : confirmer, rejeter, demander une nouvelle évaluation.

Adapter le langage à un parent non technique.

Créer tests fonctionnels et rapport.
