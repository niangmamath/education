# Prompt 08.1, implémenter les lacunes localisées

Créer LocalizedGap avec compétence, contexte, attendu, observé, preuves, règle, gravité, priorité, confiance, statut et dates.

## Règles V0.1

- écart attendu/observé ;
- échecs répétés ;
- prérequis manquant ;
- absence de progrès.

## Garde-fous

- statut initial Candidate ;
- preuve insuffisante réduit la confiance ;
- cause probable explicitement marquée comme hypothèse ;
- aucune étiquette stigmatisante.
