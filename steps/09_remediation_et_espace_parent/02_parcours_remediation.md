# Prompt 09.2, créer un parcours de remédiation multi-source

Implémenter un exemple :

1. ressource Khan Academy ou CK-12 ;
2. simulation PhET si pertinente ;
3. activité H5P ou quiz Django ;
4. réévaluation ;
5. décision de suivi.

Ne marque jamais la compétence acquise sur la seule ouverture d’une ressource.

Créer une démonstration reproductible et rapporter les limites.
