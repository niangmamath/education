# Prompt 09.3, implémenter l’espace parent

## Contenu

- résumé de l’enfant ;
- priorité actuelle ;
- action de la semaine ;
- consigne courte ;
- échéance ;
- déclaration de séance ;
- observation familiale marquée comme telle ;
- progression récente.

## Critères

- compréhension en moins de deux minutes ;
- aucune comparaison avec d’autres enfants ;
- mobile et accessible ;
- permissions testées.
