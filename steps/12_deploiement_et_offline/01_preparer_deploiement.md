# Prompt 12.1, préparer le déploiement de démonstration

## Travaux

- Docker de production léger ;
- Gunicorn ;
- Nginx si nécessaire ;
- variables d’environnement ;
- collectstatic ;
- migrations ;
- health check ;
- HTTPS selon l’hébergement ;
- procédure de rollback ;
- fixtures de démonstration séparées.

Ne déploie pas de données réelles.

Créer un guide reproductible et le rapport.
