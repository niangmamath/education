# Prompt 12.3, effectuer le spike Kolibri/offline

## Objectif

Évaluer une démonstration locale de contenus offline sans bloquer la release.

## Travaux possibles

- installation locale ;
- import d’un canal public autorisé ;
- accès depuis un second appareil sur réseau local ;
- étude des endpoints publics ou exports documentés ;
- mapping minimal avec StudentConnect.

## Sortie

- démonstration si faisable ;
- sinon rapport précis de faisabilité et recommandations.

Ne dépend pas des API internes instables de Kolibri.
