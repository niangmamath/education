# Étape 02.2, initialiser Next.js

## Prérequis

Lire les fichiers racine et le dernier rapport disponible.

## Objectif

Créer le frontend Next.js 16 TypeScript strict avec Tailwind CSS 4.

## Travaux obligatoires


1. Initialiser Next.js App Router dans `apps/web`.
2. Activer TypeScript strict.
3. Installer Tailwind CSS 4.
4. Créer layouts racine, métadonnées, page santé et page d’accueil de chantier.
5. Installer sans utiliser encore toutes les dépendances : TanStack Query, Zustand, React Hook Form, Zod, Radix UI, Lucide, Framer Motion, Recharts et next-intl selon besoin immédiat.
6. Ajouter ESLint, formatage et scripts.
7. Vérifier build production.


## Critères d’acceptation


- [ ] `dev`, `lint`, `typecheck` et `build` passent.
- [ ] Tailwind fonctionne.
- [ ] Aucune page ne dépend de données fictives codées en dur sans mention.
- [ ] La page initiale reste légère.


## Livrables

Application Next.js minimale et rapport.

- Exécuter les tests pertinents.
