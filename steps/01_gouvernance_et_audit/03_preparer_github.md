# Prompt 01.3, préparer GitHub Project et la gouvernance du dépôt

Vérifie puis complète la configuration de GitHub sans créer de doublons.

## À vérifier

- vues : Backlog, Sprint actuel, Roadmap, Livrables, Bugs et blocages, Validation finale ;
- champs : Status, Priority, Iteration, Epic/Module, Type, MoSCoW, Estimate, Start date, Target date, Deliverable, Risk, Acceptance ;
- itérations I0 à I3 ;
- labels module, type et priorité ;
- templates Feature, Bug, Decision et Test ;
- modèle de pull request ;
- protection de branche si autorisée.

## À créer dans le dépôt

- `.github/ISSUE_TEMPLATE/`
- `.github/pull_request_template.md`
- `CONTRIBUTING.md`

Ne modifie pas les paramètres distants si l’agent ne dispose pas des autorisations. Documente les commandes et actions manuelles nécessaires.

## Livrables

- fichiers GitHub
- checklist d’actions manuelles
- rapport de réalisation
