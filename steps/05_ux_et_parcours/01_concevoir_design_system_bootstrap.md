# Prompt 05.1, concevoir le design system Bootstrap

Créer un système d’interface simple, enfant-friendly et accessible.

## Exigences

- Bootstrap 5 uniquement ;
- mobile-first à 360 px ;
- couleurs accompagnées de labels ou icônes ;
- composants pour niveau 0 à 5, ressource, lacune, plan et progression ;
- textes courts et non stigmatisants ;
- navigation clavier et contrastes vérifiés.
