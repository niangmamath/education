# Prompt 05.2, maquetter les parcours Élève et Parent

## Écrans minimaux

- connexion ;
- accueil parent ;
- dossier élève ;
- carte de compétences ;
- catalogue ;
- parcours d’apprentissage ;
- activité/évaluation ;
- lacune et explication ;
- plan de correction ;
- progression avant/après.

## Critères

- un parent comprend niveau, priorité et prochaine action en moins de deux minutes ;
- un élève atteint l’activité recommandée en trois interactions maximum ;
- vue mobile vérifiée.

## Livrables

- maquettes ou templates statiques ;
- carte de navigation ;
- rapport de réalisation.
