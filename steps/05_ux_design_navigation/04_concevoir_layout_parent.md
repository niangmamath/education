# 05.4, concevoir le layout Parent

## Objectif

Créer le socle responsive de l’espace Parent avec données de démonstration clairement identifiées.

## Zones attendues

- en-tête et identité StudentConnect ;
- sélection de l’enfant ;
- navigation principale ;
- synthèse de progression ;
- emplacement du score académique futur ;
- lacunes détectées ;
- activités recommandées ;
- notifications ;
- paramètres et aide.

## États à démontrer

- chargement ;
- aucun enfant associé ;
- aucune donnée récente ;
- erreur de chargement ;
- contenu disponible.

## Acceptation

- [ ] Responsive mobile et bureau.
- [ ] Navigation clavier possible.
- [ ] Hiérarchie des titres cohérente.
- [ ] Données fictives explicitement signalées.
- [ ] Aucun calcul académique présenté comme réel.
