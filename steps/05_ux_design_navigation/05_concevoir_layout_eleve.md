# 05.5, concevoir le layout Élève

## Objectif

Créer une interface simple pour les élèves de 6 à 11 ans, distincte de l’espace Parent.

## Zones attendues

- salutation neutre ;
- objectif du moment ;
- activité recommandée ;
- progression simple ;
- raccourci vers les activités ;
- espace récompenses futur ;
- aide accessible.

## Principes

- phrases courtes ;
- actions principales évidentes ;
- pas de pression, culpabilisation ou classement social ;
- rétroactions descriptives ;
- icônes accompagnées de texte ;
- aucun mécanisme de récompense trompeur.

## Acceptation

- [ ] Action principale repérable.
- [ ] Utilisable au clavier.
- [ ] Responsive.
- [ ] Parent et Élève visuellement distincts mais cohérents.
- [ ] États d’erreur compréhensibles par un enfant.
