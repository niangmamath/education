# Prompt 02.2, configurer PostgreSQL et Docker Compose

## Travaux

- créer ou corriger `docker-compose.yml` ;
- configurer PostgreSQL ;
- fournir des volumes nommés et variables d’environnement d’exemple ;
- ajouter une commande de migration ;
- ajouter une procédure de sauvegarde et restauration locale ;
- vérifier le démarrage sans écraser une base existante.

## Critères

- Django se connecte à PostgreSQL ;
- migrations de base réussies ;
- redémarrage reproductible ;
- procédure documentée ;
- aucun secret commité.
